# n8n-nodes-basevn-income

n8n community node for [BaseVN - App Income](https://base.vn) integration.

[![NPM Version](https://img.shields.io/npm/v/n8n-nodes-basevn-income)](https://www.npmjs.com/package/n8n-nodes-basevn-income)

## Installation

Install from npm in your n8n root directory:

```bash
npm install n8n-nodes-basevn-income
```

Or install via n8n Community Nodes:
1. Go to **Settings → Community Nodes**
2. Click **Install**
3. Enter `n8n-nodes-basevn-income`

## Prerequisites

- n8n instance (self-hosted or cloud)
- Base.vn account with BaseVN - App Income access
- API access token (`access_token_v2`)

## Configuration

1. Add new credentials: **BaseVN - App Income API**
2. Enter your Base.vn domain (e.g., `example.base.vn`)
3. Provide your `access_token_v2`
